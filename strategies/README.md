# strategies/ — 전략별 스펙·실증 기록

전략마다 **확정 스펙**과 **실증 결과(라이브/백테스트)**를 한 폴더에 모은다.
매매 추이를 전략별로 누적 기록하는 용도이며 git으로 추적한다.

## 구조

```
strategies/
  README.md              ← 이 파일(전략 목록·현황 인덱스)
  <전략>/
    SPEC.md              ← 확정 스펙(파라미터·안전장치)
    live/
      YYYY-MM-DD.md      ← 라이브 모의/실거래 실증 일지(하루 1파일)
    backtest/            ← (전략에 백테스트가 있으면) 결과·해석
```

실증 규칙(하루 1파일·검증 가능한 수치만)은 아래 **전략 현황** 표 밑에 정리한다.

- **DeviationScale 검증 필요 가정(회의 2026-10-01).** 9월 모의 161건은 비용 전 +21bp, 비용 23bp, 순 −10만(t=0.18)이라 엣지가 확인되지 않았다. 감사 전 잠정 수치다.
  - D1 회전 — 비용이 비용 전 수익을 넘은 것은 회전(1억 계좌 17거래일 12.5회) 탓이다. 10-01에 재진입 대기 43200초, 모의 신규 진입 마감 1450으로 바꿨다. 확인: 하루 매수 명목이 줄고 매매당 순수익이 오르는지.
  - D2 역선택 — 후보 전체 당일 평균 +1.17%에 실제 산 종목 −0.47%다. 기준선 아래 지정가가 떨어지는 종목에서만 체결되기 때문이라고 본다(추정). 확인: `scripts/check_runtime_health.py` 역선택 행.
  - D3 재인수 — 재기동 때 잔고 전량을 DevScale 몫으로 되찾아 수동·다른 전략 보유분까지 팔 수 있다. 순수량(매수 합 − 매도 합)으로 바꾼다.
  - D4 청산선 — 산 뒤 최대 상승 중앙값 1.40%에 익절 +3% 도달 16%다. 익절 1.5%·당일 청산은 2주 표본으로 판정하지 않고, 1년 리플레이(D-111)에 1틱 불리한 체결을 넣어 다시 본다. 합격선: 세후 +10bp/건, 300건 이상, t≥2.
  - D5 구조 — 9월 상승률 상위 20의 73%가 후보에 있었지만, 역배열(149건)·과확장(+5% 초과 76건)이라 눌림 조건상 사지 못했다. 이 몫은 아래 후보 전략이 맡는다.
- **후보 전략(회의 2026-10-01, 미구현).** 근거와 반박은 그날 회의 기록에 있다.
  - 52주 신고가 — 한국 포함 근거가 가장 강하다(월 단위). TargetBasket 비중표의 입력으로 넣는다(자본 추가 없음). 가정: 상장폐지 종목 일봉이 있어 생존 편향 없이 2010~2021 walk-forward가 가능하다.
  - 강한 종목 첫 VWAP 눌림 — 09:30 등락률 +6~20%·거래대금 상위 40 종목이 오전 고점에서 38~62% 되밀려 VWAP ±0.5%에 온 뒤 1분 고가를 되찾으면 산다. 손절은 눌림 저점 −0.3%, 15:10 청산. 학술 근거는 없고, 거래대금 상위 추격은 한국에서 반대 증거가 있어 추격이 아니라 재돌파만 산다. 가정: VI·+20% 초과 종목을 빼면 손절이 체결된다. 표본은 09:30 시점 순위로만 고른다. 시가 범위 돌파(ITB)를 대조군으로 둔다. 합격선: 비용 0.31% 뒤 PF 1.3 이상, 200건 이상.
  - 테마 폭 — 테마 안 +3% 넘게 오른 종목 비율과 대장을 후보 점수에 넣고, 대장 +8%·폭 40% 초과 때 덜 오른 2~3위를 산다. 한국 테마 자체의 근거는 없다. 가정: 날짜별 테마 스냅샷(01:16 수집)이 그날 시점을 고정한다. 과거 구성에는 사후 테마가 섞여 있어 쓰지 않는다.
  - 두 장중 후보의 선결 조건 — 시세판 전 종목을 1분마다 저장하는 것(당일 순위를 그 시점 기준으로 재현). 10-01부터 쌓는다.
- **실증 규칙:** 하루 = 라이브 1파일(`live/YYYY-MM-DD.md`). 같은 날은 같은 파일에 갱신, 날짜가 바뀌면 새 파일. `/trade-log`가 `quant_trader.log`에서 재생성한다. 추측·과장 금지, 로그로 검증 가능한 수치만 — 체결통보가 남은 건만 원 단위 실현손익 확정.
