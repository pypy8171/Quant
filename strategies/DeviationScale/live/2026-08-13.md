## 4. 문제·진단 (심각도 순)

### (1) KIS 서버측 HTTP 500 폭풍 — 세션 전체 지배
`inquire-price`·`inquire-time-itemchartprice`·`inquire-index-price`·`inquire-daily-itemchartprice` 거의 전부 500. 대부분 재시도 복구, **일부 3/3 소진 실패 → 일봉 못 채워 프리필터 `데이터부족=1`**. 주문 RTT 7.6s로 지연. 우리 버그 아닌 KIS 상태로 판단하나, 재시도가 초당한도 잠식하는 악순환 여지.

### (2) DEVSCALE_006340 명목 한도 사다리 스래싱 — 진짜 조율 갭
14:39:
```
신호: 006340 BUY 0        ← qty=0 무의미 신호
신호: 006340 BUY 0
신호: 006340 BUY 111
신호: 006340 BUY 112
취소 무시 — 취소 대상 없음 (B:1, B:2)
거부 — 종목당 명목 한도 초과 (10222870 > 7500000)
거부 — 종목당 명목 한도 초과 (10157180 > 7500000)
```
`pos=562 live=2` → **보유(562주 ~8.5M)만으로 명목캡 7.5M 초과**인데 사다리가 계속 BUY 111/112를 밀어 매번 거부. 08-11 no-change 가드는 "봉 미변경 억제"라 **"이미 캡 초과라 어차피 거부될 계단"은 미필터**. 게이트가 막아 사고는 없으나 헛발주+취소무시 로그 누적. `BUY 0` = 계단 하나가 qty=0으로 새는 것.

### (3) 하락 추세에 눌림 매수로 붙는 구조 (전략 관점)
당일손익 −52k→−188k 출혈. **006340은 수급상 외인·기관 순매도 상위**인데 DEVSCALE는 562주 들고 더 사려 함 = 분산 구간 물타기. "정배열 눌림"이 하락 초입을 눌림으로 오판하는 케이스.
