# 스터디 20 · 거시 국면 오버레이 — 사전등록 (2026-09-20, 결과 보기 전 확정)

> 정본 스펙: [research/RESET_2026-09-19_R2/macro-quant.md](../../RESET_2026-09-19_R2/macro-quant.md) §2·§2-4. 이 파일은 그 숫자를 실행 순서대로 옮긴 것이고, 스펙과 다르게 한 곳은 §5에 적었다.
> 합격 숫자의 뜻과 출처(계산한 값·관행·고른 값 구분): [../READING_NUMBERS.md](../READING_NUMBERS.md).
> 실행 전에 이 파일을 먼저 쓰고, 결과를 본 뒤에는 §1~§4 숫자를 바꾸지 않는다.

## 1. 가설

성장·물가·유동성·위험선호 네 축의 국면 점수로 코스피 노출 배수(0~1)를 정하면, 가격 파생 지표만 쓴 방어(스터디 08 M1·M5)와 달리 낙폭을 줄이면서 연 1%p 안에서 수익을 반납한다.

## 2. 설계(고정)

- **대상 곡선**: 코스피 단일 곡선 `PYQuant/.index_cache/idx__KS11_1996-01-01_2026-08-15_adj.parquet`(7,305봉). 동일가중·저변동성 바스켓(2019~)은 이번 실행에서 빼고 다음 실행으로 넘긴다.
- **결정 시각**: 평일 D 08:50 KST. 시리즈 행은 `published_at < D`(날짜 단위)인 것만 보인다. 관측치마다 **첫 발표치**만 쓴다.
- **노출**: `e_D = macro_scale(D−1 08:50)`, D 시가 체결, D 시가 → D+1 시가 수익에 `e_D`를 곱한다. 노출 변경분 `|e_D − e_{D−1}|`에 비용 0.23%.
- **축 점수**: 변환 → robust z(중앙값·MAD·1.4826, 창 W 월간 120관측·주간 520·일간 2,520, 최소 36개월/156주/250일, clip ±3) → 가중 평균(유효 시리즈 2개 미만이면 축 NaN → 중립).
- **국면**: 성장·물가 부호는 데드밴드 δ=0.25 이력 규칙. 재판정은 성장·물가 축의 월간 시리즈가 새로 보인 날에만. 배수 확장 1.00 / 과열 0.75 / 수축 0.50 / 회복 0.75.
- **일간 배수**: `m_R = 1.0 (R ≥ −1) / 0.75 (−2 ≤ R < −1) / 0.5 (R < −2)`, `m_L = clip(1 + 0.1·min(L, 0), 0.8, 1.0)`, `macro_scale = round(clip(base·m_R·m_L, 0, 1), 0.05)`.
- **셀**: `market_only`(SOX·달러지수 캐시·원달러 캐시·VIX·HY·코스피 200일선·외국인 20일 — 성장·물가 축 없음, base 1.0 고정) → 가격 파생 축의 한계 확인용, 채택 근거 아님. `four_axis`(위 표 전체) → 판정 대상.
- **기간·창**: 1999~2025 연도 창 27개. 중심 파라미터 고정(δ 0.25, W 120, 수축 0.5). 학습 창은 파라미터를 바꾸지 않으므로 "앞 3년"은 z 창의 예열 구간 역할만 한다.
- **격자(공개용)**: δ {0.15, 0.25, 0.35} × W {96, 120, 144} × 수축 {0.4, 0.5, 0.6} = 27셀. `trials_prior = 27`. 격자는 강건성 표시용이고 셀 고르기에 쓰지 않는다.

## 3. 합격 숫자(모두 비용 뒤)

| 번호 | 항목 | 기준 |
|---|---|---|
| ① | 확장 − 수축 월수익 차이 t(Newey-West 3) | ≥ 2.0 |
| ② | 연도 창 27개 중 오버레이 Calmar > 매수 후 보유 Calmar | ≥ 16 |
| ③ | 중심 ±1 이웃 6셀의 Calmar 개선 부호 | 전부 중심과 같음 |
| ④ | MDD 상대 감소 | ≥ 20% |
| ⑤ | CAGR 반납(매수 후 보유 − 오버레이) | ≤ 1.0%p/년 |
| ⑥ | 국면 전환 | ≤ 6회/년 |
| ⑦ | 월 초과수익(오버레이 − 매수 후 보유) t(Newey-West 3) | ≥ 1.5, Deflated Sharpe p < 0.05(N=27) |

①~⑦ 전부 통과 → `macro_apply = true`. ④⑥ 통과·⑤만 미달이면 축소판(수축 0.5만, 나머지 1.0, 일간 배수 끔) 한 번 더 판정. 그것도 미달이면 `macro_apply = false`로 적고 표시만 한다. 미달이면 파라미터를 더 뒤지지 않는다.
