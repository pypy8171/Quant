# BT-01 · 모멘텀 × 국면필터, 최근 1~5년 롤링 (기준선)

**질문.** 시총 상위 100에 6-1 모멘텀 + 200MA 국면필터를 굴리면 비용 물고 벤치를 이기나? 기간에 견고한가?

**설정.** `CrossMomentumStrategy` lb120/skip20/top10/rb5, regime ON, 동일가중, datagokr 일봉, 유니버스 시총상위100(PIT), END=2026-08-05 고정. 창 길이만 1~5년으로 변화.
