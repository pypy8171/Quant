# 32 국내 지수 장중 낙폭 규칙 — 국면 점수 −11 청산과 비교·병행

질문: 실계좌 DevScale은 보유를 하루 넘겨 들고 가고, 폭락 방어는 국면 점수 청산선(−11, 스터디 26)에만 기댄다.
코스피·코스닥이 장중 X% 빠지면(전일 종가 대비 / 당일 고점 대비) 신규 매수를 멈추거나 보유를 파는 규칙이
점수 −11 청산보다 낫거나, 둘을 같이 쓰면 나은가.

## 방법

`index_drawdown_guard.py`가 스터디 26의 시세 캐시와 점수 복원(`replay_regime_score.py`의 `build_daily`·`build_hourly`)을
그대로 불러 쓰고, 그 위에 지수 낙폭 규칙을 얹는다. 점수 −11 단독 결과는 26과 맞는다(코스닥 일봉 −1.04 vs 26의 −1.0,
1시간봉 −4.06 vs −4.1 %p/년).

| 항목 | 내용 |
|---|---|
| 갈래 | daily 2015-01-02~2026-09-30(2,882일, 네이버 일봉) · hourly 2024-05-09~2026-09-30(581일, Yahoo ^KS11·^KQ11 1시간봉) |
| 장중 경로 | 봉 안을 시가→극값→극값→종가로 본다. 음봉은 고가 먼저, 양봉은 저가 먼저 |
| 규칙 | `prev X`: 지수 ≤ 전일 종가×(1+X%) · `high X`: 지수 ≤ 개장 뒤 지나온 최고값×(1+X%). X = −1.5·−2·−2.5·−3·−4·−5. 신호와 보유 대상은 같은 지수 |
| 병행 | `규칙|score-11`: 지수 규칙과 점수 −11 중 먼저 닿은 쪽에서 판다 |
| 청산 | 선을 지나는 순간 선 값에 판다(개장 시가가 이미 선 아래면 시가). 왕복 0.215% |
| 되사기 | `next_open` 다음 거래일 시가(그날 시가가 다시 규칙에 걸리면 하루 더 밖) · `same_close` 그날 종가 |
| 정지 | 발동 지점에서 샀다면 그날 종가·다음날 종가까지 수익 — 전체 날 평균(시가 매수)과의 차이 |
| 기간 분리 | 갈래마다 앞 70% / 뒤 30%. daily 경계 2023-03-13, hourly 경계 2026-01-09 |
| DevScale 적용 | 스터디 28 `zone_grid_days.tsv` 실계좌 칸(`z_lo8_up5_tp5`, 2025-09-19~2026-09-18, 172건, 세후 59.2만). 발동 시각(hourly 경로)에 들고 있던 종목을 1분봉 종가로 팔았다면 원래 경로 대비 얼마였나 |

  prev −4.0 앞 70%(+0.48) 하나다.
- 청산 뒤 놓친 반등(되산 시가 / 판 값 − 1)의 평균은 −0.05~+0.81%로 0과 구분되지 않는다(t −0.16~+1.90). 손해의 대부분은
  잦은 발동의 비용(연 20~60회 × 0.215%)과, 크게 빠진 날 다음날 반등(2026-03-04 코스닥 −14.0% 다음날 +14.1%,
  2024-08-05 −11.3% 다음날 +6.0%)을 놓친 데서 온다.
- 최대낙폭은 좁은 X에서 줄어든다(hourly 코스닥 prev −2.0 −47.4→−36.0%). 그 대가가 연 −10%p 안팎이다.
- 최악 20일 하루 평균 손실은 보유 −7.3%(일봉 코스닥)에서 prev −2.0 −1.7%, prev −3.0 −2.7%, 점수 −11 −5.9%로 줄어
  지수 규칙이 점수보다 폭락일에 일찍 닿는 것은 맞다(`crash_days.tsv`). 그래도 1년 전체로는 회복을 놓친 몫이 더 크다.

## 판정

- **지수 낙폭 청산은 넣지 않는다.** 전일 종가 기준은 어느 X에서도 지수 보유보다 나빴고(코스닥 X 6개 × 앞/뒤 × 두 갈래 24칸 중 플러스 1칸),
  고점 기준은 촘촘한 경로(hourly)에서 음수, 일봉의 플러스는 경로 근사가 만든 것이다. 점수 −11과 병행하면 더 나빠진다.
  DevScale 1년 표본에서도 같은 방향이다. 낙폭은 줄지만(코스닥 hourly prev −2 MDD −47→−36%) 연 −10%p 안팎을 낸다.
- **점수 −11 청산은 그대로 둔다**(이 스터디의 범위 밖 — 26 판정 유지).
- **정지는 보류.** 코스닥 전일 종가 −2.5% 신규 매수 정지는 지수 기준 8칸 같은 방향(0.16~0.42%p)이지만 크기가 작고,
  DevScale 1년에서 막히는 매수는 5건(−8.5만)이라 종목 수준에서 확인되지 않았다. 넣는다면 청산 없이 정지만,
  코스닥 전일 종가 −2.5%가 후보다.

## 한계

- 폭락일 표본이 적다. 일봉 코스닥 −5% 이하 마감일은 12년에 수십 일이고 2026년에 몰려 있다. hourly 뒤 30%(175일)에
  2026년 폭락이 거의 다 들어 있어 앞/뒤가 서로 다른 장세를 본다.
- 장중 경로는 근사다. 일봉은 OHLC 4점, 1시간봉도 봉 안 순서를 종가로 정한다. 선 값에 판다는 가정은 연속 감시·슬리피지 0이다.
  실제 엔진의 국면 점수는 3분 주기이고, 지수 낙폭 규칙을 넣으면 시세 갱신 주기가 체결가를 정한다.
- DevScale 적용은 사후 근사다. 매수 시각은 첫 3분봉, 존 이탈 매도 시각은 넘긴 보유면 09:03, 같은 날 산 것은 15:15로 가정했고,
  발동일을 하루씩 따로 셌다(다음날 다시 발동하면 비용을 한 번 더 문다). 동시 보유 상한은 하네스에 없다.
  입력 `research/studies/28_devscale_zone_width/zone_grid_days.tsv`(79MB)는 로컬에만 있어 다른 트리에서는 `--no-devscale`로 돈다.
- 신호와 보유 대상을 같은 지수로 맞췄다. DevScale 종목은 시총·거래대금 상위 100이라 코스피 비중이 크다.
- 같은 데이터(26 캐시)를 26에서 이미 봤다. 격자는 X 6개 × 기준 2개 × 병행 여부 × 되사기 2개 × 지수 2개 × 갈래 2개다.

재실행(약 65초, 26 캐시와 위 tsv가 있으면 내려받기 없음, 같은 입력에서 산출물 6개 비트 동일 확인 2026-10-01, HEAD 546f2d4):

    py -X utf8 research/studies/32_index_drawdown_guard/index_drawdown_guard.py [--no-devscale]

(보유 기준 최악 15일과 규칙별 매도 값), `devscale_grid.tsv`, `devscale_events.tsv`(종목·발동별 차이), `metrics.json`.
