# 스터디 21 · 거시 국면 오버레이 — 배수를 축 상태 변경 시에만 갱신 — 사전등록 (2026-09-20, 결과 보기 전 확정)

> 스터디 20([../20_macro_overlay/PREREG.md](../20_macro_overlay/PREREG.md))의 재실행이다. 20은 `macro_apply=false`로 끝났고 원인 진단은
> 합격 숫자의 뜻과 출처(계산한 값·관행·고른 값 구분): [../READING_NUMBERS.md](../READING_NUMBERS.md).
> "일간 배수가 노출 변경 비용을 27년 누적 12.2%(`four_axis`)·17.8%(`market_only`) 냈다"였다. 오너 결정 6(2026-09-20)으로 배수 갱신 주기를 **축 상태 변경 시**로 정했고
> (정본 [research/RESET_2026-09-19_R2/macro-quant.md](../../RESET_2026-09-19_R2/macro-quant.md) §2-3), 이 파일은 그 한 가지만 20과
> 다르게 한 채 같은 합격 숫자로 다시 판정한다(D-103: 결과를 본 뒤 조건을 바꾸지 않고, 바꾸려면 새 번호로 사전등록한다).
> 실행 전에 이 파일을 먼저 쓰고, 결과를 본 뒤에는 §1~§4 숫자를 바꾸지 않는다.

## 1. 가설

위험선호·유동성 배수를 매일 다시 계산하지 않고 축 상태(구간)가 바뀐 날에만 바꾸면, 노출 변경 비용이 사라지는 만큼
스터디 20의 CAGR 반납(−1.35%p)이 ⑤ 기준 안(≤ 1.0%p)으로 들어오고, 국면 신호가 살아 있다면 MDD 감소 ④(≥ 20%)도 보인다.
둘 다 안 보이면 국면 신호 자체가 코스피에서 방어력이 없다는 뜻이고, 그러면 파라미터를 더 뒤지지 않는다.

## 2. 설계(고정) — 스터디 20 §2와 같고, 다른 곳은 굵게

- 대상 곡선·결정 시각·노출·체결 비용 0.23%·축 점수·국면 판정·기본 배수·셀·기간·창·격자 27셀·`trials_prior = 27`: 스터디 20 §2 그대로.
- **배수 갱신 규칙 `scale_update = on_state_change`**(`PYQuant/features/regime_axes.py::Parameters`):
  - 위험선호 R은 구간 3개 — 경계 −1·−2, 배수 1.0 / 0.75 / 0.5(스터디 20 `m_R`의 문턱 그대로).
  - 유동성 L은 구간 3개 — 경계 −0.5·−1.5, 배수 1.0 / 0.9 / 0.8(스터디 20 `m_L = clip(1 + 0.1·L, 0.8, 1.0)`을 0.1 단위로 끊은 것, 경계는 그 중간점).
  - 구간 이동은 성장·물가 부호와 같은 데드밴드 이력 규칙 — 아래 경계를 δ만큼 더 내려가야 한 칸 아래로, 위 경계를 δ만큼 더 올라가야 한 칸 위로(δ는 격자 값과 공유, 중심 0.25). 첫 유효값은 데드밴드 없이 구간을 정한다. NaN이면 그대로.
  - 따라서 `macro_scale = round(clip(base · m_R · m_L, 0, 1), 0.05)`는 국면·R 구간·L 구간 중 하나가 바뀐 날에만 움직인다.
  - `entry_halt = (R < −2.5)`는 그대로 매일 판정한다(노출이 아니라 신규 진입 정지 표시라 비용이 없다).
- 20과 같은 러너를 인자만 바꿔 돌린다(`--scale-update on_state_change --study-dir research/studies/21_macro_overlay_hold`). 격자 27셀·축소판도 같은 규칙으로 돈다.

## 3. 합격 숫자(모두 비용 뒤) — 스터디 20 §3과 같다

| 번호 | 항목 | 기준 |
|---|---|---|
| ① | 확장 − 수축 월수익 차이 t(Newey-West 3) | ≥ 2.0 |
| ② | 연도 창 27개 중 오버레이 Calmar > 매수 후 보유 Calmar | ≥ 16 |
| ③ | 중심 ±1 이웃 6셀의 Calmar 개선 부호 | 전부 중심과 같음 |
| ④ | MDD 상대 감소 | ≥ 20% |
| ⑤ | CAGR 반납(매수 후 보유 − 오버레이) | ≤ 1.0%p/년 |
| ⑥ | 국면 전환 | ≤ 6회/년 |
| ⑦ | 월 초과수익(오버레이 − 매수 후 보유) t(Newey-West 3) | ≥ 1.5, Deflated Sharpe p < 0.05(N=27) |

①~⑦ 전부 통과 → `macro_apply = true`. ④⑥ 통과·⑤만 미달이면 축소판(수축 0.5만, 나머지 1.0, 일간 배수 끔) 한 번 더 판정.
그것도 미달이면 `macro_apply = false`로 적고 표시만 한다. 미달이면 파라미터를 더 뒤지지 않는다.

같이 적을 진단 항목(합격 판정에 안 씀): 노출 변경 비용 합계(`total_cost_pct`, 20은 12.2%·17.8%)와 노출 < 1 일수 — 갱신 규칙이 비용을 실제로 줄였는지 확인용.
