# GUARDRAILS — 백테스트 규율 (현 단계 최선, 개선 가능)

> **이 문서의 성격**: 절대불변의 법이 아니라 **현 단계에서 자기기만을 막는 최선의 규율**이다. 백테스트 방식은 아직 시작 단계이고 계속 개선한다. 이 경계들도 **가정을 명시하고 회의(RESEARCH_COUNCIL)로 개정할 수 있다.** 규율의 목적은 개선을 막는 게 아니라 **조용한 오염(silent contamination)·사후정당화를 막는 것**이다. 바꾸되, 무단·즉흥으로 바꾸지 않는다.
>
> `bias-auditor`는 작업 시작 시 이 파일을 먼저 읽고 각 편향 판정의 대조 기준으로 쓴다. 이 문서에 "확인불가"로 남은 항목은 통과가 아니라 미해결이다.
>
> _근거·코드앵커는 2026-08-17 4개 도메인 에이전트(backtest-runner·bias-auditor·data-sourcer·strategist) 합동 심의._

## ① 엔진·데이터 단일소스 — 불변식 불가침, 수정은 규율 하에 허용
"파일 절대 미수정"이 아니라 **불변식 불가침**이 본질이다. 버그 수정·데이터 확장은 **가능하다**. 다만 아래 4조건을 모두 충족한다(무단·즉흥 수정 금지). 하나라도 불확실하면 수정 보류 → 회의 안건화.

- **대상**: `PYQuant/backtest/engine.py`(재현성의 심장 — look-ahead 차단·체결·비용·결정론), `PYQuant/data/yfinance_source.py`(데이터 소스). 데이터는 단일 진입점 `IndexSource().get_historical_ohlcv` 하나만 통한다.
- **수정 4조건**:
  1. **사전등록 가정** — 무엇을·왜 바꾸는지, 어떤 기존 가정을 대체하는지 커밋 메시지 + 해당 study README에 명시.
  2. **재현 회귀(골든 케이스)** — 고정 골든 케이스 1건을 변경 전후 재실행. 동일이면 통과, 숫자가 바뀌면 **어느 결과가 왜 바뀌는지** 명문화(조용한 변화 금지).
  3. **불변식 보존** — look-ahead 차단(`_AsOfKisAdapter` / `visible = b.date <= date`)·결정론(`sorted()`·global seed)·체결시점(신호 다음봉 시가)·비용 ON을 훼손하지 않는다.
  4. **단일 진입점·캐시 정합** — 엔진 계약(authenticate/get_historical_ohlcv/prefetch/universe_top/ticker_name) 유지. 소스의 데이터 형태·수정주가·기간을 바꾸면 **캐시(`.yf_cache`) 무효화**(parquet가 티커-only 키잉이라 소스만 바꾸면 스테일 캐시가 조용히 과거를 오염).
- 헬퍼는 **import 재사용**(새 엔진 분기 금지 = 단일소스 유지).

> _앵커: `engine.py`(체결·비용·결정론 집약), `PYQuant/data/yfinance_source.py`(auto_adjust·캐시), `PYQuant/data/index_source.py`._

## ② 스코프: 현 연구군은 index-macro 고정 — 종목레벨/섹터는 게이트 통과 시 별도 트랙
**절대금지가 아니다.** 금지되는 것은 *현 index-macro 연구군 내부에서 정적 유니버스로 breadth/dispersion을 파생하는 것*(생존편향)뿐이다. 종목레벨·섹터는 로드맵상 별도 트랙이며, 데이터 게이트를 통과하면 열린다. 근거는 정책이 아니라 **검증가능성**: 지수·매크로만 PIT 재현이 되어 생존편향이 구조적으로 0.

- **현 연구군(06_bear/07_crisis/BT-09 등)**: 지수·매크로 시계열만. 정적 유니버스(`universe_kospi.py` 등)로 breadth 파생 금지.
- **종목레벨 트랙 — 확보됨 ✅ (게이트 통과 시 즉시 허용)**: PIT 유니버스가 **이미 배선·실증**됨 — `datagokr_source.universe_top(on_date)`(data.go.kr getStockPriceInfo `basDt` 단면, 상폐·신규 자연반영, 2020~ 캐시 검증). 정적 리스트 금지, PIT 단면만. 아래 **②-b survivorship 게이트** 6조건 통과가 선결.
- **섹터 트랙 — 보류 ⚠️**: 업종/섹터 **PIT 분류의 무료 경로 미확보**(pykrx MDC 분류 API는 LOGOUT 차단). data-sourcer 게이트(분류 소스 확정) 전까지 **엣지 판정 금지**, 예열·탐색만 허용. ※ 전략적으론 섹터(업종지수형)가 편향이 옅어 먼저였으나, 실증상 병목은 섹터 분류데이터이고 종목레벨 PIT가 오히려 준비됨.
- **수급 기반 breadth**: 무료 백테스트 경로 없음(KIS 30일·KRX 차단) → forward 적재 전엔 **라이브 전용**.

### ②-b PIT 종목레벨/섹터 게이트 (deny-by-default, 입증책임=연구자)
아래 6조건을 `data-sourcer`가 데이터로 증명한 경우에만 트랙이 열린다. 미증명·확인불가가 하나라도 있으면 **②의 금지가 자동 복귀**한다.
1. **소멸 종목 포함** — 시점 t 유니버스에 그때 거래가능했던 모든 이름(상폐·부도·합병·편출 포함). 오늘 생존 종목만으로 과거 구성 금지.
2. **PIT 멤버십** — 편입/편출 발효일 기준 as-of 구성(현재 구성의 과거투영 금지).
3. **종결수익 포착** — 상폐 시 마지막 종가 forward-fill로 손실 동결 금지, **터미널 리턴(→0 또는 인수가)으로 마킹**. (반례: KIS 엔진 `_buyhold_equity`의 상폐 후 종가 전방채움 = 이 게이트가 금지할 패턴.)
4. **상장일 인지** — IPO 이전 날짜에 그 종목 선택 금지.
5. **기업행위 조정** — 분할·병합·스핀오프·배당 조정.
6. **출처 증명** — 유니버스가 발효일 있는 과거 멤버십 파일에서 왔음을 증명(오늘 리스트 재구성본 아님).

## ③ 룩어헤드 삼중차단
초안의 이중차단(strict + e[t-1])은 코드와 일치 확인됨. 다만 **전역통계 누출**이라는 세 번째 벡터를 명시적으로 막는다.

- **익스포저 e[t]는 close t 까지의 정보로 산출**, 수익 = e[t-1] × 지수수익 (`run_curve`: `pos=e[t-1]; net[t]=pos*ret[t]-turn*(cost/2)`).
- **US→KR 시차**: KR(^KS11) 벤치마크에선 US/글로벌 신호(^GSPC·^IXIC·^VIX·^TNX·^SOX·CL=F·DXY)를 `strict=True`(직전 세션값 `dates_src < d`)로 정렬. 미국장은 한국장 이후 마감 → 같은날 US종가를 KR신호로 쓰면 1일 룩어헤드. (KRW는 동일세션이라 strict 제외.)
- **매크로 = 신호전용**: 수익곡선 ret[t]는 오직 거래대상 지수 종가로만 생성. TNX/oil/DXY/KRW로 수익곡선 만드는 범주오류 금지.
- **전역통계 금지 (신설)**: 파생지표·정규화·변동성 앵커는 **롤링/확장창(t 이전만)**으로만 산출한다. 전표본(홀드아웃·미래 포함) mean/std/quantile 정규화는 strict·e[t-1]을 통과해도 **미래정보 누출**이다. (반례: `bt09_strategies.py`의 N4 `leak` mode = 전 구간 변동성 앵커 → 격리·비교 전용, **판정근거 불가**.) 단, 단위·정합성 탐지용 전 구간 상수 통계는 예외로 명시 기재.

## ④ 정직성 — 전략 내부 + 스캔 행위 자체
전략 하나를 정직하게 만드는 규율에, **여러 전략을 스캔하는 행위 자체의 편향**을 더한다.

- **1차 지표 = 단일 연결곡선 Calmar 1개(검정 1회)**. 이벤트별은 진단·중앙값만(판정 근거 아님).
- **사전등록 임계값 + 전체 스윕 공개**(best 셀만 보고 금지). 비용 감도 **0.21 / 0.5 / 1.0%**.
- **홀드아웃 2022 잠금**: train=2022 제외, holdout=2022. 결측신호 → **중립(e=1)** + **커버리지 명시**.
- **가족단위 다중검정 고지 (신설)**: 전략 N종 × 벤치 M종을 스캔하면(예: BT-09 13×2) 우연으로도 소수가 BH를 이긴다. 어떤 생존 전략도 **2022 홀드아웃 독립확인 통과**만 결론 후보이며, 전체 (전략×시장×스윕셀) 개수를 함께 보고한다. 헤드라인 연결곡선 Calmar는 2022 포함 **기술통계**이고, 승격 게이트는 **홀드아웃 단독성과**임을 분리 명시.
- **임계값 사전등록 원장 (신설)**: 스윕하지 않는 하드코딩 임계는 값·근거·확정일자를 README 사전등록 원장에 남긴다(사후조정 감사가능). 미기재 임계 = "확인불가 = CONDITIONAL".
