## 방향성 타임라인 — 백테스트가 어떻게 진화했나

각 단계 = **무엇을 물었나 → 무엇을 발견했나 → 그래서 다음 방향**. 상세는 BACKTEST_LOG의 해당 실행.

### #1 (2026-08-05) — 기준선: 모멘텀 × 국면필터, 최근 1~5년 롤링
- **질문:** 6-1 모멘텀 + 200MA 국면필터가 비용 물고도 벤치를 이기나? 기간에 걸쳐 견고한가?
- **발견:** 상승장에선 α 크지만 **전 구간 MDD -22~-36%로 게이트(≤15%) 전부 불합격.**
- **→ 방향:** 수익률이 아니라 **①낙폭 통제**가 1순위 과제.

### #2 (2026-08-05) — 변동성 타게팅 사이징 도입
- **질문:** 노출을 변동성으로 조절하면 샤프 지키며 MDD를 게이트까지 낮추나? (변수: 사이징만)
- **발견:** MDD 전 구간 8~12%p 개선, 샤프 유지, **1년 MDD -11.61%로 게이트 첫 통과.** 단 거래수 급증·α 음수전환(벤치가 풀노출이라 당연).
- **→ 방향:** vol_target 채택. 다만 α는 상승장 표본뿐 → **약세장 OOS 검증 필요.**

### #3 (2026-08-05) — 2022 약세장 격리 OOS + 국면필터 ON/OFF ablation
- **질문:** 모멘텀 엣지가 약세장에서 살아남나? 국면필터의 실제 가치는?
- **발견:** **모멘텀 단독(OFF)은 약세장에서 벤치보다도 나쁨**(-35% vs -20%, 모멘텀 크래시 실증). regime ON은 1년 내내 현금화 → **-35% 재앙 완전 회피.** 시스템의 약세장 엣지 = 모멘텀이 아니라 **국면 오버레이의 하방 컷.**
- **→ 방향:** 손실통제 레버는 regime으로 확정. 다음은 **개별 신호 정밀도(필터)** 탐색.

### #4 (2026-08-07) — 올해 월별 시작 민감도 + C1 개별추세필터 도입
- **질문:** 올해 각 월부터 시작 시 오늘까지 기대수익률? 개별 추세필터가 수익을 높이나?
- **발견:** **시작월이 결과를 지배**(1·2·4월 +30~43% vs 6·7월 마이너스) — 진입 국면이 지배 변수. 모든 시작월에서 α는 양수(regime 하방 방어 작동). **C1 추세필터는 2026 강세장에서 baseline과 완전 동일(inert).** 표본 N=10~89로 게이트 미달.
- **→ 방향:** 소표본 한계 → **전기간 재검증 필수.**

### #5 (2026-08-07) — 지표 4종 전기간 재검증 (2021~2026, N≥750)
- **질문:** 추세필터·절대모멘텀·변동성조정 중 표본≥200에서 baseline을 견고하게 이기는 지표가 있나?
- **발견:** **채택 게이트 통과 지표 0개.** trend200은 미세 우위지만 MDD 오히려 악화(가설 반증), absmom 완전 inert, vol_adjust는 악화(#4 1월 급등은 운). **유효한 유일 레버는 여전히 regime.** α 절대값은 생존편향으로 신뢰 불가.
- **→ 방향:** 지표 튜닝으로는 한계. **진짜 병목 = 데이터.**

## 현재 상태 / 다음 데이터 단계

- **확정 사실:** (1) 진입 시점(국면)이 수익을 지배, (2) **regime 필터가 낙폭 방어의 실제 레버**(vol_target 보조), (3) 테스트한 개별 지표(추세·절대모멘텀·변동성조정)는 **견고한 개선 없음.**
- **최우선 병목:** 유니버스가 "오늘 생존 99종목" 고정 → **생존편향**으로 모든 절대 α가 낙관 편향. 지표 판정을 신뢰하려면 편출·상장폐지 포함 **point-in-time 유니버스 OHLCV** 필요.
