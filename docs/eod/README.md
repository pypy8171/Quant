# 장 종료 리뷰 색인

매매한 날의 장 종료 리뷰를 하루 1파일로 둔다. `/eod-review`가 생성하고, 장 마감 후 자동으로 돈다.

각 문서는 네 갈래로 나눈다 — 코드적인 문제 / 매매적인 문제 / 주문관련 문제 / 추가 발견.
사실 수집은 `scripts/eod_collect.py`와 `scripts/parse_quant_log.py`가 하고, 판단만 문서에 쓴다.

전략별 실증 일지(`strategies/<전략>/live/`)와 역할이 다르다. 일지는 그 전략이 어떻게 거래했는지의
기록이고, 여기는 시스템 전체에서 무엇이 고장났고 무엇을 고치기로 했는지의 기록이다.
