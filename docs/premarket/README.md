# 장전 시황 브리핑 색인

평일 아침 클라우드 루틴(`market-brief`, 08:30 KST 기동)이 쓴 장전 브리핑을 하루 1파일로 둔다.
2026-09-04~09-11분은 노션에 쌓이던 것을 09-13에 옮겨 왔다. 루틴은 저장소를 못 써서 계속 노션에 쓰고, 아침 세션
(`/auto-trade-day` 1단계)이 그 페이지를 여기로 옮긴다. 루틴 프롬프트 정본은 [ROUTINE_PROMPT.md](ROUTINE_PROMPT.md).
대시보드 `research/dashboard/dashboard.html`의 **장전 브리핑** 탭이 이 폴더를 읽는다
(`PYQuant/dashboard/build_dashboard.py`, 표 파싱은 각 문서 머리의 `| 항목 | 값 |` 표).

장 종료 리뷰(`docs/market_close/`)와 짝이다. 아침에 무엇을 보고 어떤 스탠스를 잡았는지가 여기에, 그날 실제로
무엇이 일어났는지가 `docs/market_close/`에 있다. 같은 날짜끼리 나란히 읽는다.

## 날짜 결함 — 파일명은 발행일, 본문은 하루 전

루틴은 08:30 KST(= 전날 23:30 UTC)에 돈다. 그 안의 모델이 UTC 날짜를 '오늘'로 잡아서 제목과 본문이
하루 전 기준으로 써졌다 — 09-10 아침 브리핑이 "내일 동시만기"라 하고, 09-11 아침 브리핑이
"오늘 동시만기"라 하는 식이다. 노션에 「09-07」이 둘이고 「09-11」이 없는 것도 같은 이유다.
09-07 한 건만 맞는데, UTC로 일요일이라 모델이 월요일로 고쳐 잡은 것으로 보인다.

여기서는 **파일명을 실제 발행일(KST)** 로 두고, 각 문서 머리에 노션 제목 날짜와 본문 기준일을 같이 적었다.
발행 시각은 노션 페이지의 마지막 편집 시각(08:42~08:45 KST)이다. 09-19에 프롬프트에 KST 날짜 규칙을 넣었으므로
(`ROUTINE_PROMPT.md` "날짜" 절) 09-14 이전 여섯 건에만 해당한다.

스탠스는 세 값이다. **관망**(신규매수 확대 안 함) · **보수**(신규는 하되 비중 줄임) · **선별**(특정 업종만 조건부 우호).
브리핑은 매크로·뉴스 기반 정성 판단이고 실제 국면(RISK_ON/NEUTRAL/RISK_OFF)은 `PYQuant/tools/macro_regime_feed.py`가
지표 8개로 따로 판정한다 — 여섯 건 모두 그 전제를 본문에 달아 두었다(당시는 코스피 이동평균 판정기였고 09-14에 지웠다, D-085).
09-19부터는 프롬프트가 같은 8개 지표 모델을 담고 있어 5절에 어림 점수와 국면을 적는다.

## 새 문서 형식

머리는 제목 · 발행 정보 인용문 · 아래 표 순서다. 대시보드가 이 표를 읽으므로 항목 이름은 바꾸지 않는다.

```markdown
| 항목 | 값 |
|---|---|
| 발행 | YYYY-MM-DD HH:MM KST |
| 본문 기준일 | YYYY-MM-DD |
| 스탠스 | 관망 · 보수 · 선별 중 하나 |
| 국면 결론 | 한 줄 |
```

본문은 `## 1.`~`## 5.` 다섯 절(한 줄 요약과 국면 결론 · 미국장·환율·야간선물 · 오늘 예정 이벤트 · 섹터/테마와
유니버스 영향 · 이 시스템 관점의 실행 함의)이다.
